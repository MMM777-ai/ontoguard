Integrations & Partners

OntoGuard is the semantic decision point. It composes with agent trust, enforcement, orchestration, and implementation partners rather than replacing them.

Agent trust and evidence

AgenTrust — TRACE Community Integration

OntoGuard produces the semantic authorization decision. Independently evidenced execution can then be represented in TRACE. The adapter verifies signed OntoGuard authorization material and independently signed execution evidence before projecting an executed ALLOW into TRACE. BLOCK, ESCALATE, or ALLOW without a valid execution receipt emit no TRACE record.

The integration was independently exercised during maintainer review before merge. Displayed status is Community Integration, not AgenTrust Verified. Full AgenTrust / TRACE integration page — Marketplace listing, 27/27 tests, $250K / $260K paths, and limits.

View integration source · View maintainer review / PR

TRACE is not OntoGuard’s native audit format. AgenTrust does not perform OntoGuard’s semantic decision. No OPAQUE partnership is claimed.

Enforcement and runtime

OntoGuard authorizes the exact proposed action. Enforcement systems consume that decision at a protected endpoint. This page describes the integration category; it does not name unimplemented product partnerships.

Agent platforms

OntoGuard can sit in an agent orchestration path as the pre-commit authorization layer: the agent proposes, OntoGuard decides, the runtime executes only when ALLOW is current and bound to the exact action.

Implementation partners

Systems integrators build the customer execution route. Read the implementation-partner split of responsibilities.

Vertical AI vendors

Product companies can embed Decision Authorization so buyers inspect governed action, not only model quality. Vendor path.

OEM / embedded licensing

OntoGuard can be licensed or embedded as the proof layer between an AI proposal and an organizational consequence. The partner retains its platform; OntoGuard adds admissibility, routing, and portable evidence. Discuss scope at mark.starobinsky@ontoguard.ai.
