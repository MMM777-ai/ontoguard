Product

Deploy OntoGuard Decision Authorization inside your execution environment.

OntoGuard Headless Decision Authorization Runtime 1.0.19 is a self-contained authorization service. It is a different version line from OntoGuard Governance Pack v1.2.0.

Self-contained

No operational dependency on the OntoGuard web application or the main source repository. Designed for deployment inside customer-controlled or confidential-computing environments.

Exact-action binding

Authorization applies to the exact proposed movement. A prior ALLOW does not survive material mutation.

Signed configuration / semantic authority

Only trusted, authenticated governance material can establish the runtime authorization context.

Authenticated governance inputs

The runtime accepts only authenticated governance material from trusted sources.

Fresh-state binding

Authorization can be bound to fresh execution state so stale approvals are not silently reused.

Controlled execution binding

An ALLOW is not a reusable blanket permission for arbitrary subsequent actions.

Durable evidence

Decision, authorization, release, and outcome evidence can be retained across the execution lifecycle.

Longitudinal governance

Decision and outcome history can support bounded behavior-over-time review. Historical metrics are not a second authorization authority.

Interoperability

Independently evidenced execution can be projected into systems such as AgenTrust TRACE. Community Integration is not AgenTrust Verified.

No OPAQUE partnership is claimed. Hardware attestation is not assumed by default. Production L5 and universal non-bypassability require deployment-route evidence.

OntoGuard Governance Pack v1.2.0 names the public artifact/schema line. OntoGuard Headless Decision Authorization Runtime 1.0.19 names the deployable runtime line.
