# IP Disclosure Boundary

This public kit is an allowlisted behavioral/evidentiary projection.

## Included because it is useful and non-implementation-specific

- governance states and lifecycle order;
- representative decision/release/no-bind outcome;
- authority and approval statuses;
- aggregate evidence/citation/causality counts;
- distinct public trust/uncertainty metrics;
- benchmark mode/sample/percentile and claim boundary;
- R7 status and threshold state;
- longitudinal status/counts and non-decisioning role;
- current-event versus controlled-fixture maturity;
- replay status and fail-closed properties;
- strict-six membership, sizes, readiness, and post-decision packaging timing;
- harness pass/warning/failure totals.

## Withheld because it may expose OntoGuard implementation IP or operational identity

- source code, source filenames, module/function names, stack traces and local paths;
- raw prompts, model outputs, evidence bodies, candidate inventories or internal provenance pointers;
- retrieval engine names, indexes, query-construction mechanics, ranking features, vector/embedding identities;
- proprietary formulas, component weights, model fingerprints and numeric R7 thresholds;
- internal run/route/attempt/receipt/evidence identifiers and internal decision/evidence hashes;
- private citation/ontology/registry contents, secrets, credentials and private signing material;
- exact controlled test-case names or internal harness anchors.

This design minimizes implementation disclosure while preserving externally useful proof. No public behavioral artifact can eliminate every theoretical inference risk; this package is designed for zero direct implementation-IP disclosure.
